# Індикатор TradingView: SMC Bot v5 (v4 + AF)

`smc_v5.pine` малює обидва сетапи Strategy v5 (Strategy v6 відрізняється лише правилом розміру між парами, яке на одному графіку не застосовується) і веде кожну угоду так само, як бектест бота:
- **v4** — свіп пулу → Shift на M5 → лімітка на краї FVG; часткова 50% на 2R, тейк 3R, після часткової стоп у беззбиток на новому свінгу M5 (режим c), закриття о 12:00 NY;
- **AF** — фейк Азії на відкритті Лондона: пробій high/low Азії (19:00–23:55 NY) у 02:00–05:00 NY, повернення в діапазон сильною свічкою → вхід по ринку проти пробою, стоп за екстремумом фейку, тейк 3R, ризик ×0.5.

## Встановлення
1. TradingView → внизу **Pine Editor** → **Створити → Індикатор**, видаліть шаблон.
2. Вставте весь текст `smc_v5.pine` → **Зберегти** → **Додати на графік** (стару версію v4 можна прибрати з графіка).
3. Графік **EURUSD або GBPUSD**. Часовий пояс графіка може бути Київ — усі правила рахуються за Нью-Йорком.
4. Для GBPUSD у налаштуваннях поставте **Спред = 1.4**.

## Що на графіку (M5)
- **v4:** мітка ▲ LONG / ▼ SHORT, клас **A** (бірюзова) або **B** (помаранчева), сетап S1/S2/+S11, бали x/4. Біла лінія — лімітка, червона — стоп (після режиму c підтягується до входу), зелена — тейк.
- **AF:** фіолетова мітка «▲ LONG AF / ▼ SHORT AF фейк Азії»; у підказці — діапазон дня в ATR(D), вхід по ринку, стоп, тейк.
- Після закриття: **✓ УСПІШНА / ✗ НЕУСПІШНА / = БЕЗЗБИТОК** і R; мітка зелена / червона; у підказці — причина (тейк, стоп, беззбиток після часткової, 12:00 NY).
- Сірі ✗ — відхилені сетапи v4 з причиною.
- Таблиця: окремо **v4** і **AF** (угоди, вінрейт, R, R з вагою ризику), A/B для v4, **разом з вагою**.

## Таймфрейми
- **M5** — повна картина. Глибина історії за таймфреймом (група «Глибина історії»): M5 — 3 дні, M15–H1 — 30, H2–H4 — 90, D і вище — 365 днів; рахується від останньої свічки, тож працює і в Симуляторі ринку.
- **H1 і вище** — мітки входів з часом (бірюзова/помаранчева = v4 A/B, фіолетова = AF), після закриття — результат; таблиця угод, вінрейту і R (v4 / AF). Сірий ○ — лімітка v4, що не виконалась. Глибина обмежена тим, скільки M5-барів віддає TradingView на вашому тарифі.

## Налаштування
- «Фільтри»: S11 і його вікно (144 бари M5 = 12 год), режим c (стоп у беззбиток після часткової).
- «AF — фейк Азії»: увімкнути/вимкнути, діапазон Азії, вікно (працює лише від 02:00 NY), тіла свічок, повернення за N барів, мін. діапазон дня (0.40 ATR(D)), буфер стопу, тейк, ризик.

## Сповіщення
Праворуч **Оповещения → Створити** → Умова: **SMC v5** → **Any alert() function call** → один раз за закриття бару. Приходять сигнали обох сетапів із входом, стопом, тейком і множником ризику.

## Відмінності від бота
- Немає синхрону з M3; POI — останній FVG H1/H4; структура H4/M15 — спрощений BOS.
- Спред фіксований; денні ліміти PRO не враховуються.
- v4 — одна угода за раз (новий сигнал замінює невиконану лімітку); AF має свій окремий слот. У боті діє загальне правило «1 позиція на пару».
Тому окремі угоди можуть відрізнятися від бектесту — для статистики покладайтесь на бота, індикатор — для очей і сповіщень.
